# Chrome & Blood Gameplay

This repository catalogs the current Chrome & Blood custom gameplay, settings, and override snapshot. Original standalone mods remain available from their Nexus pages.

This archive is not the complete Chrome & Blood modlist and is not a drop-in full installation. It is a pinned working pre-release asset for the collection tooling.

This is an unofficial fan work and is not approved or endorsed by CD PROJEKT RED. The archive is distributed free of charge and is not paywalled.
